# Бережно

Персональное wellness-приложение для мягкой подготовки к беременности: привычки, питание, движение, цикл и назначения врача — без перегрузки, с адаптацией под реальную жизнь. Работает на iPhone (иконка на экране «Домой»), Mac и Windows, офлайн и с синхронизацией через облако.

**Главный принцип:** пропущенное не превращается в долг, в дни «мало сил» остаётся только главное, ничего не становится обязательным без согласия.

## Что умеет

- **Главная** — план дня с кольцом прогресса; режимы «У меня мало сил», «Я в разъездах», поздний подъём, сбитый сон, ПМС, 1–2 день менструации (определяется по циклу), день отдыха; действия «Выполнено», «Короткая версия», «Перенести», «Пропустить сегодня», «Изменить расписание», «Скрыть»; вода, фрукты и овощи, ближайший приём пищи, события цикла, неделя.
- **Привычки** — полная и минимальная версии, расписание (каждый день, по дням, рабочие, выходные), пауза, «главная» привычка, идеи новых привычек по одной; тёплая вода утром как исходная; мёд — необязательный, по умолчанию выключен.
- **Питание** — 14 любимых рецептов без граммовки и 11 новых с точной граммовкой (без духовки, печени, имбиря, сельдерея и лимона), примерная пищевая ценность; меню на 7 или 14 дней с повтором прошлого меню, порциями, остатками и оценками; автоматический список покупок с объединением и пересчётом, отметками «куплено» и домашними запасами; «Перекусить сейчас» с фильтрами и своим каталогом товаров ВкусВилла и Азбуки вкуса; анализ рациона без диагнозов.
- **Цикл и овуляция** — прогноз следующей менструации, овуляции и фертильного окна с неопределённостью, история циклов, симптомы в любой день, тесты на овуляцию (4 на первый месяц, фото по желанию, остаток, ориентир начала тестирования), модуль тестов скрывается без удаления истории; режим беременности.
- **Мои назначения** — инозитол, фолиевая кислота, витамин D и любые другие: дозировка и время вводятся по назначению врача, статусы «Принято / Пропущено / Не отмечено», история, предупреждение о дублировании компонентов.
- **Движение** — йога 2 раза в неделю с переносом, каталог для новичка с плеером и таймером, короткие и бережные практики, свои видео; разминки «Шея и плечи», глаза, спина, запястья, общая, ходьба — только в рабочие дни; ручной ввод активности.
- **Рабочий график** — ручная отметка плавающих смен (офис, вне офиса, поездка), заполнение на несколько недель.
- **Календарь** — день, неделя, месяц; все категории с фильтром; заметки дня.
- **Знания** — 16 материалов с уровнем доказательности, источником и датой проверки; «Добавить в привычки», «Сохранить», «Не показывать».
- **Статистика** и **годовой план** — по реальным отметкам, без диагностики.
- **Напоминания** — в приложении и выгрузкой в системный календарь (.ics) для фоновых сигналов.
- **Облако** — Supabase: вход по почте, синхронизация iPhone ↔ Mac ↔ Windows, офлайн-очередь, разрешение конфликтов с сохранением проигравших версий, экспорт, удаление данных и аккаунта.

## Структура

```
src/
  main.tsx, index.html, sw.template.js   точка входа, страница, service worker
  app/        оболочка, навигация, напоминания, вычисления плана
  screens/    экраны (главная, питание, цикл, движение, …)
  ui/         компоненты интерфейса, плеер упражнений, графики
  lib/        логика без интерфейса: план дня, цикл, покупки, анализ, ICS, статистика
  store/      хранилище IndexedDB, синхронизация, клиент Supabase, действия
  data/       типы, встроенные рецепты, упражнения, статьи, идеи привычек
supabase/migrations/001_init.sql          схема базы, RLS, функции
tests/      unit, sql (PostgreSQL), e2e (Playwright), mock (модель сервера)
```

Приложение не ставит диагнозов, не назначает лечение и не обещает наступление беременности.

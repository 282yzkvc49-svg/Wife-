# Ограничения и будущие этапы

## Уведомления на iPhone (Safari и PWA)

- Веб-приложение, добавленное на экран «Домой», может получать **push-уведомления** только на iOS/iPadOS 16.4 и новее, только после разрешения пользователя и только если их отправляет **сервер** (Web Push). Само приложение в фоне не работает и не может «проснуться» в нужное время.
- Во вкладке Safari (не установленной на экран «Домой») уведомления на iPhone недоступны.
- **Что сделано в этой версии:**
  - напоминания внутри открытого приложения: показ в нужное время, «Открыть», «Через 15 минут», без дублей (каждое — не чаще раза в день), учёт рабочих дней, дней йоги, окна тестов, тишины в разъездах;
  - системные уведомления, пока приложение открыто (Mac, Windows, установленное приложение на iPhone — если разрешены);
  - **выгрузка в системный календарь (.ics)** с сигналами — работает в фоне на iPhone, Mac и Windows (Outlook) без сервера. Для назначений можно скрыть названия.
- **Следующий этап (Web Push):** Supabase Edge Function с ключами VAPID + расписание pg_cron раз в минуту + таблица подписок. Оценка: 1–2 дня разработки, бесплатный тариф Supabase подходит.

## Apple Watch и Apple Health (HealthKit)

- У веб-страниц нет доступа к HealthKit — ни в Safari, ни у приложения на экране «Домой». Поэтому интеграция **не имитируется**: шаги, прогулки и тренировки вносятся вручную (раздел «Движение → Активность»), и всё остальное работает без них.
- **Варианты на будущее:**
  1. **Отдельное приложение для iPhone** (Swift, HealthKit): запрос разрешения на каждый тип данных (шаги, тренировки и их длительность, активная энергия), фоновая доставка новых записей, отправка в ту же базу Supabase под тем же аккаунтом. Нужны Mac с Xcode и учётная запись Apple Developer Program ($99 в год) для установки дольше 7 дней и для TestFlight. Оценка: 1–2 недели на минимальную версию.
  2. **Быстрая альтернатива — «Команды» (Shortcuts)**: личная команда читает шаги за день из «Здоровья» и открывает приложение с готовой записью. Не требует App Store, но запускается вручную или по автоматизации и менее надёжна. Оценка: 1 день.

## Магазины (ВкусВилл, Азбука вкуса)

- Открытого API для каталогов, цен и наличия нет, поэтому приложение **не показывает выдуманные товары, цены и остатки**.
- Есть идеи перекусов по категориям и времени и **свой каталог**: товары добавляются вручную; состав, упаковка, цена, ссылка и наличие показываются только если заполнены, у цены — дата проверки.
- Интеграция возможна только при появлении официального технического способа.

## Медицинская часть

- Приложение не ставит диагнозов, не назначает и не меняет лечение, не обещает наступление беременности.
- Дозировки назначений вводит пользователь; приложение их не подбирает.
- Календарный прогноз овуляции — оценка с диапазоном неопределённости; он не подтверждает овуляцию. Тест на овуляцию выявляет всплеск ЛГ, но тоже не подтверждает, что овуляция состоялась.
- Библиотека содержит только материалы, сверенные с источниками (ВОЗ, NHS, CDC, FDA, NCCIH, AASM и др.) на дату проверки. Новые материалы нужно добавлять после такой же проверки.
- Иллюстрации и видео к упражнениям не встроены, чтобы не расходиться с инструкциями; можно добавлять свои проверенные видео-ссылки.

## Отличия от предпочтительного стека ТЗ

- Вместо Next.js — сборка esbuild: GitHub Pages — статический хостинг, серверные функции Next.js там не работают. Роль защищённого API выполняют функции PostgreSQL (`push_changes`, `pull_changes`, `delete_my_data`, `delete_my_account`) под защитой RLS.
- Клиент Supabase — собственный минимальный (Auth + RPC), без внешних зависимостей.
- Ингредиенты рецептов хранятся внутри записи рецепта, а не отдельной таблицей — так рецепт меняется атомарно и не «разваливается» при конфликтах синхронизации.

# Политика конфиденциальности «Бережно»

Приложение личное: им пользуется один человек, данные принадлежат только ему.

**Какие данные хранятся.** То, что вы вносите сами: настройки, привычки и отметки, назначения и их приём, данные цикла, симптомы и самочувствие, результаты тестов (и фото, если вы его добавили), меню, рецепты, покупки, рабочий график, активность, заметки, напоминания. Приложение не собирает геолокацию, контакты, рекламные идентификаторы и не подключает аналитику.

**Где хранятся.**
- На устройстве — в хранилище браузера (IndexedDB).
- В облаке — только если вы вошли: в **вашем собственном** проекте Supabase (PostgreSQL). Каждая строка базы привязана к вашему аккаунту, а правила Row Level Security разрешают читать и менять её только вам. В приложении используется лишь публичный ключ; секретные ключи не хранятся ни в коде, ни на устройствах.
- История изменений важных записей (назначения, рецепты, цикл, тесты, привычки, настройки) хранится в облаке для защиты от потери данных и доступна только вам.

**Кому передаются.** Никому. Нет рекламы, таргетинга и сторонних трекеров. Медицинские данные не используются ни для каких целей, кроме показа вам. Ссылки на внешние источники открываются в браузере — приложение ничего туда не передаёт. В адресах страниц нет личных данных.

**Безопасность.** Соединение с облаком — только по HTTPS. Вход по почте и паролю (Supabase Auth). Сессия хранится на устройстве; выйти можно в Настройках, с удалением данных с устройства или без.

**Ваши права и управление данными.**
- Экспорт всех данных в файл — Настройки → «Экспорт данных».
- Удаление всех данных в облаке и на устройствах — Настройки → «Удалить все данные» (другие устройства очистятся при следующей синхронизации).
- Удаление аккаунта вместе со всеми данными — Настройки → «Удалить аккаунт».
- Любой модуль можно отключить; отключение не удаляет данные.

**Резервное копирование.** Облако Supabase на бесплатном тарифе не делает автоматических резервных копий с восстановлением на момент времени, поэтому раз в месяц полезно сохранять экспорт в «Файлы» или iCloud Drive. Резервная копия — обычный JSON-файл; храните его так же бережно, как медицинские документы.

**Связь с медициной.** Приложение не является медицинским изделием, не ставит диагнозов и не назначает лечение.

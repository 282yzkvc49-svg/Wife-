# Установка и запуск «Бережно»

Всё можно сделать с iPad или iPhone в Safari. Порядок: облако → публикация → установка на устройства.

## 1. Облачная база Supabase (≈5 минут, бесплатно)

Нужна, чтобы данные были одни и те же на iPhone, Mac и Windows. Без неё приложение тоже работает, но только на одном устройстве.

1. Зайдите на supabase.com → **Start your project** → войдите (можно через GitHub).
2. **New project**: имя `berezhno`, придумайте пароль базы (сохраните его, в приложении он не нужен), регион — ближайший (например, Frankfurt или Stockholm) → **Create new project**. Подождите 1–2 минуты.
3. Слева **SQL Editor** → **New query** → вставьте целиком содержимое файла `supabase/migrations/001_init.sql` → **Run**. Должно появиться «Success. No rows returned». Скрипт можно запускать повторно — он ничего не удаляет.
4. **Settings → API Keys**: скопируйте **Publishable key** (или legacy **anon public**). Адрес проекта (**Project URL**, вида `https://xxxx.supabase.co`) показывается в окне **Connect** на главной странице проекта.
   Секретный ключ (`secret` / `service_role`) никуда не копируйте — приложение его не принимает.
5. **Authentication → URL Configuration → Site URL**: вставьте адрес приложения `https://282yzkvc49-svg.github.io/wife-/`. Тогда ссылки из писем (подтверждение почты, смена пароля) будут открывать приложение.
6. По желанию: **Authentication → Sign In / Providers → Email → Confirm email** можно выключить — тогда аккаунт заработает сразу, без письма. Если оставить включённым, после регистрации откройте письмо на том же устройстве и затем войдите.

Адрес и ключ можно либо ввести в приложении (Настройки → Облако — один раз на каждом устройстве), либо передать разработчику, чтобы их «вшили» в сборку — тогда на устройствах нужно будет только войти.

## 2. Публикация на GitHub Pages

Код лежит в ветке `main`, готовое приложение — в ветке `gh-pages`.

1. Репозиторий на GitHub → **Settings → Pages**.
2. **Build and deployment → Source: Deploy from a branch** → Branch: **gh-pages**, папка **/(root)** → **Save**.
3. Через 1–2 минуты вверху страницы появится адрес приложения: `https://282yzkvc49-svg.github.io/wife-/`.

Если репозиторий приватный, Pages на бесплатном тарифе недоступен — сделайте его публичным. В репозитории нет личных данных: они хранятся только на устройствах и в вашей базе Supabase.

## 3. Установка на iPhone

1. Откройте адрес приложения **в Safari**.
2. «Поделиться» → **На экран «Домой»** → Добавить. Появится иконка «Бережно».
3. Запускайте с иконки. Сначала войдите в облако (кнопка «Уже пользуюсь на другом устройстве» на первом экране или Настройки → Облако), потом пользуйтесь.
   У приложения на экране «Домой» своё хранилище, отдельное от вкладки Safari, поэтому входить нужно именно в установленном приложении.

## 4. Mac и Windows

- **Mac**: откройте адрес в Safari → меню «Файл» → **Добавить в Dock** (macOS Sonoma и новее) или просто держите вкладку. В Chrome: значок установки в адресной строке.
- **Windows**: откройте адрес в Edge или Chrome → значок «Установить приложение» в адресной строке.
- Войдите тем же аккаунтом — данные синхронизируются.

## 5. Напоминания в фоне

Раздел «Напоминания» → **Скачать файл календаря (.ics)** → откройте файл → «Добавить все». На iPhone лучше выбрать отдельный календарь «Бережно». После изменения расписания выгрузите файл снова и удалите старые события этого календаря, чтобы не было дублей.

## 6. Резервная копия

Настройки → **Экспорт данных** → «Сохранить в Файлы». Восстановление: Настройки → «Восстановить из копии». При восстановлении более новые записи не перезаписываются старыми.

## 7. Обновление приложения

Новая версия публикуется в ветку `gh-pages`. При следующем запуске появится баннер «Доступна новая версия» → **Обновить**. Если баннер не появился, закройте приложение смахиванием и откройте снова.

## Для разработчика

```bash
npm run build          # сборка в dist/ (плоская структура для GitHub Pages)
npm run dev            # пересборка при изменениях + сервер http://127.0.0.1:5173
npm run typecheck      # проверка типов
npm test               # unit- и интеграционные тесты (node:test)
npm run test:sql       # миграция и RLS на локальном PostgreSQL 16
npm run test:e2e       # сквозные проверки в Chromium (Playwright) + офлайн + все экраны
```

Параметры облака для сборки (необязательно): переменные окружения `SUPABASE_URL` и `SUPABASE_ANON_KEY` или файл `app.config.json` по образцу `app.config.example.json`. Публикуемый ключ — только publishable/anon.

Публикация вручную: собрать `dist/` и положить его содержимое в корень ветки `gh-pages`.
